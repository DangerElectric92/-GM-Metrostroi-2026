
  ##  ПОЛНАЯ ИНСТРУКЦИЯ ПО УСТАНОВКЕ МОДУЛЯ АСНП "METROSTROI 2026" 


## [ШАГ 1: УСТАНОВКА МОДУЛЯ СОКЕТА В GARRY'S MOD]
1. Зайдите в папку вашего сервера
2. Перейдите по пути: ...\garrysmod\lua
3. Проверьте, есть ли там папка "bin". Если её нет — создайте папку с именем "bin".
4. Скопируйте файл "gmsv_gwsockets_win32.dll" из папки Сокет и положите его 
   строго по пути: garrysmod\lua\bin

## [ШАГ 2: ПРОШИВКА ЭКРАНА АСНП (ARDUINO NANO)]
1. Подключите Вашу плату Arduino Nano к компьютеру по USB.
2. Откройте папку "XLoader" и запустите файл "XLoader.exe".
3. Настройте программу строго по пунктам:
   - Hex file: нажмите "..." и выберите наш файл "asnp_rus_nano.ino.hex" из папки ASNP_RUS_METROSTROI\Прошивка АСНП V1.0 arduino    \build\arduino.avr.nano
   - Device: выберите "Duemilanove/Nano(ATmega328)"
   - COM Port: укажите номер порта Вашей платы (можно узнать в Диспетчере устройств)
   - Baud rate: оставьте 57600
4. Нажмите кнопку "Upload" внизу окна программы.
   (Если программа зависла — смените Baud rate с 57600 на 115200 и нажмите Upload снова).
5. После завершения прошивки на экране АСНП загорится приветственная заставка.

## [ШАГ 3: НАСТРОЙКА И ЗАПУСК PYTHON-МОСТА]
1. Запустите файл "bridge.exe" (папка bridge)
2. Рядом автоматически создастся файл "settings.txt".
3. Откройте файл "settings.txt" через Блокнот.
4. Замените порт "COM18" на РЕАЛЬНЫЙ номер порта Вашей Arduino Nano и сохраните файл.
5. Снова запустите "bridge.exe". Это окно должно оставаться ОТКРЫТЫМ во время всей игры.

## [ШАГ 4: УСТАНОВКА lua]
1. В папке lua лежит файл "metrostroi_to_arduino.lua"
2. Скопируйте и положите его на Ваш сервер Garry's Mod строго в папку:
   C:\server\garrysmod\lua\autorun\server 
3. Запускайте сервер, заходите в игру, спавните состав и отправляйтесь в рейс!

## *ПРИМЕЧАНИЕ:  папка server и диск С: могут отличаться, у вас может быть совершенно другой диск и наименование папки, в которой располагаются файлы сервера, ОБРАТИТЕ НА ЭТО ВНИМАНИЕ!


## Модуль имеет полную обратную связь! Если Вы сели в кабину с выключенным 
## тумблером на столе — АСНП в игре автоматически выключится сам. При включении 
## тумблера на ходу экран мгновенно обновится до текущего состояния поезда.
